One original one-line cat joke — an entry for make.fun's "The One-Line Cat Joke That Lands" bounty ($2 in USDC).

## The joke

> My cat doesn't knock things off the table out of spite — she's conducting layoffs, and my phone was middle management.

118 characters, one line. The full line also lives in `joke.txt`.

## Run it

```sh
python3 main.py
```

`main.py` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
